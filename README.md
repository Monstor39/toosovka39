# DUBAI PARTY — сайт продажи билетов

Одностраничный сайт с заставкой-афишей и двумя билетами. Оплата картой через **ЮKassa**.

## Как запустить

1. Установи [Node.js](https://nodejs.org) (версия 18 или новее).
2. Открой папку проекта в терминале и установи зависимости:
   ```
   npm install
   ```
3. Скопируй файл `.env.example` в `.env` и впиши свои ключи из личного кабинета ЮKassa
   (Настройки → Магазин → shopId и секретный ключ):
   ```
   YOOKASSA_SHOP_ID=твой_shopId
   YOOKASSA_SECRET_KEY=твой_секретный_ключ
   ```
4. Запусти сайт:
   ```
   npm start
   ```
5. Открой в браузере: **http://localhost:3000**

> Без ключей ЮKassa сайт откроется и билеты покажутся, но кнопка оплаты выдаст
> ошибку — это нормально, просто впиши ключи в `.env`.

|-----|------|

## Важно про оплату

- Цены хранятся на сервере (`config.js`) — их нельзя подделать из браузера.
- Секретный ключ ЮKassa живёт только в `.env` и никогда не попадает в браузер.
- Для боевого сайта нужно выложить проект на хостинг с HTTPS и указать в `.env`
  свой домен в `RETURN_URL`, а в личном кабинете ЮKassa — адрес вебхука
  `https://твой-домен/api/yookassa-webhook`.
- Чтобы билет автоматически уходил на почту после оплаты — допиши отправку письма
