# DUBAI PARTY — сайт продажи билетов

Одностраничный сайт с заставкой-афишей и двумя билетами (обычный и VIP-столик).
Оплата картой через **ЮKassa**. После оплаты покупатель получает уникальный код.
На входе охрана проверяет коды через Telegram-бота.

## Как запустить локально

1. Установи [Node.js](https://nodejs.org) (версия 18 или новее).
2. Открой папку проекта в терминале и установи зависимости:
   ```
   npm install
   ```
3. Скопируй файл `.env.example` в `.env` и впиши свои значения (см. ниже).
4. Запусти сайт:
   ```
   npm start
   ```
5. Открой в браузере: **http://localhost:3000**

> Без ключей ЮKassa сайт работает в **тест-режиме**: оплата имитируется, код
> выдаётся сразу. Впишешь ключи ЮKassa в `.env` — включится реальная оплата.

## Настройки в `.env`

| Переменная | Зачем |
|-----------|-------|
| `TELEGRAM_BOT_TOKEN` | Токен бота охраны от @BotFather |
| `TELEGRAM_ADMIN_CHAT_ID` | Твой Telegram ID — туда падают уведомления о покупках |
| `SECURITY_PASSWORD` | Кодовое слово, которым охрана входит в бота |
| `YOOKASSA_SHOP_ID` / `YOOKASSA_SECRET_KEY` | Ключи ЮKassa (пусто = тест-режим) |
| `RETURN_URL` | Куда вернуть покупателя после оплаты |
| `ADMIN_PASSWORD` | Пароль для служебной страницы `/admin.html` |

Файл `.env` **никогда не попадает в репозиторий** (он в `.gitignore`).

## Бот охраны

Охрана пишет боту **кодовое слово** (`SECURITY_PASSWORD`) → получает доступ.
Дальше:
- присылает код билета → бот отвечает тип билета и кнопки
  **✅ Подтвердить проход / ❌ Отмена** (код гасится один раз);
- **📊 Статистика** — сколько продано, сколько сейчас внутри, сколько ушло;
- **🕒 История проходов** — кто и когда прошёл;
- **🏃 Отметить уход** — отметить ушедших, чтобы видеть реальное число людей внутри.

## Где что менять

| Что | Файл |
|-----|------|
| Заставка (афиша) | `public/hero.png` — замени картинку с этим же именем |

| Внешний вид | `public/style.css` |

## Важно про оплату

- Цены хранятся на сервере (`config.js`) — их нельзя подделать из браузера.
- Секретный ключ ЮKassa живёт только в `.env` и никогда не попадает в браузер.
- Для боевого сайта нужен хостинг с HTTPS: указать в `.env` свой домен в `RETURN_URL`,
  а в личном кабинете ЮKassa — адрес вебхука `https://твой-домен/api/yookassa-webhook`.
